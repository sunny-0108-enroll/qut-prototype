1. 개요

  • 견적 요청(RFQ) 접수부터 계약까지의 업무 흐름(8단계)과 단계별 기능 설계를 검토함.
  • 남은 설계 항목 중 상당수는 영업부의 실제 업무 방식에 따라 달라지므로 영업부 인터뷰로 확인이 필요함.
  • 개발 전에 기술적으로 불확실한 두 가지(지난 견적 자료 검색, 도면 인식)를 작은 시험으로 먼저 확인할 계획임.
  • 본 자료는 인터뷰 주제와 기술 검증 계획을 정리한 것임.

2. 영업부 인터뷰 주제

  • 검토 중 나온 확인 질문과 미결·정의 필요 사항을 주제별로 묶은 목록임.
  • 질문은 대표 질문만 적었으며, 세부 질문은 인터뷰 때 함께 확인함.
#주제왜 필요한가대표 질문결과가 반영되는 곳
1참여 판단 기준 AI가 만드는 참여 판단 자료가 실제 판단 기준과 맞아야 함
  • 지금은 견적 요청을 받은 뒤 언제(접수 직후 / 시방서 검토 후), 무엇을 근거로 참여 여부를 판단하는가
  • 대표의 참여 승인 기준은 무엇인가
  • 대표의 반려는 '불참' 결정인가, '자료 보강 후 재검토' 요청인가
  • 불참하는 건은 어느 정도이며 주된 이유는 무엇인가
 참여 판단 화면, 대표 승인 화면, 불참 사유 분류
2견적 형식과 단가·공수 기준 AI 물량·원가 계산의 기준이 되는 자료임
  • 주로 받는 견적 형식은 무엇인가(단위당 단가형 / 물량표 항목별 금액 채우기형)
  • 자재·노임·장비 단가는 어디서 가져오고, 누가 얼마나 자주 갱신하는가(구매 이력 / 공급사 견적 / 물가정보지)
  • 노임은 어떤 기준(시중노임단가 / 실투입 인건비 / 발주처 기준)으로 잡으며, 지역별로 더하는 비용은 무엇인가
  • 발주처 자료끼리 수치가 다를 때 지금은 어떻게 처리하는가(한쪽 선택 / 가정 명시 / 발주처 질의)
 물량·원가 계산 기준, 단가 자료의 관리 주체와 갱신 방식
3영업이익(%) 결정 방식 견적 금액과 협상 중 금액 계산에 직접 쓰임
  • 영업이익(%)은 누가, 어떻게 정하는가(담당자가 정하고 위에서 확인 / 위에서 정해 줌)
  • 견적 전체에 하나로 적용하는가, 항목별로 다르게 적용하는가
  • 원가의 어느 부분에 붙이는가(원가 전체 / 노무비·경비 등 일부)
 견적서 금액 계산, 협상 단계의 영업이익 자동 계산
4사내 견적서 양식과 부가 제출 서류 AI가 만드는 견적서와 결재 자료의 형식을 정해야 함
  • 내부 결재에 쓰는 사내 견적서 양식이 있는가, 어떤 칸(항목별 원가, 영업이익, 합계, 견적 조건, 가정·예외 사항 등)이 있는가
  • 견적서와 함께 주로 내는 부가 서류(안전관리계획서 등)는 무엇이며, 얼마나 자주 요구되는가 새 기능 후보
 회사 표준 견적서 양식, 부가 서류 자동 작성 기능의 대상 범위
5기술평가·가격 협상 진행 방식 제출 뒤 견적서가 어떻게 바뀌고 누가 승인하는지 정해야 함
  • 기술평가를 거치는 건은 얼마나 되고, 기술평가에서 탈락하는 경우가 있는가
  • 기술평가 중에도 항목별 가격 조정이 오가는가, 최종 가격 협상과 따로 진행되는가
  • 기술평가 답변으로 범위·사양이 바뀌어 물량·원가를 다시 계산하는 경우가 있는가
  • 협상 중 금액이 바뀌면 대표 승인을 다시 받는가, 담당자가 바로 받는가 임원을 거치는가, 기준(할인 한도 등)이 따로 있는가
 견적서 변경 이력(Rev) 관리, 협상 금액 승인 절차
6수주 결과와 사후 분석 결과 기록이 쌓여야 다음 견적에 참고할 수 있음
  • 결과는 어떤 문서로 받는가(가격·기술 협상서, 수주통보서, 계약서), 수주통보서와 계약서는 따로 오는가
  • 실주 원인은 지금 어떻게 파악하며, 주로 어떤 원인이 많은가
  • 유찰은 얼마나 자주 있는가, 발주처 사정에 의한 취소나 진행 중 포기는 어느 단계에서 얼마나 있는가
  • 수주 뒤 계약 단계에서 금액이 바뀌는 경우가 있는가
 결과 입력 화면(수주 / 실주 / 유찰, 취소는 별도), 지난 견적 참고 자료(인사이트 데이터)의 항목
7결재·권한·견적 관리 방식 사용자별 권한과 견적 관리 번호 체계를 정해야 함
  • 영업 내부에서 견적을 검토·승인하는 단계가 있는가, 있다면 누가 누구에게 받는가
  • 영업부 직원이면 누구나 다른 담당자 건의 원가·영업이익까지 봐도 되는가
  • 견적 번호·프로젝트 번호·견적서 Rev 표기 규칙이 있는가
  • 같은 공사를 다시 견적하는 경우(재입찰·재견적)는 얼마나 되고, 지금은 어떻게 관리하는가
 사용자 권한, 결재 흐름, 관리 번호 형식
8지난 견적 자료 정리 협조 기술 검증 ①은 영업의 판단이 있어야 진행 가능함
  • AI가 지난 견적에서 뽑은 요약 항목 초안에 '중요 / 필요 없음 / 빠진 것' 표시를 해 줄 수 있는가(작성이 아니라 선택)
  • 지난 견적에서 실제로 찾아보고 싶은 것을 질문 10개 정도로 알려 줄 수 있는가(예: "울산 지역 배관 공사 중 감리 상주 조건이 있었던 건")
  • 시범 결과를 표본으로 확인할 시간을 언제 잡을 수 있는가
 지난 견적 요약 양식, 기술 검증 ① 일정

3. 인터뷰 진행안

회차주제대상비고
1회1. 참여 판단 기준
2. 견적 형식과 단가·공수 기준
3. 영업이익(%) 결정 방식		영업 임원, 견적 담당
  • 견적 금액이 나오는 데 필요한 기준이라 가장 먼저 확인함
  • 사전 요청: 사내 견적서 엑셀 1부(영업이익 계산식 확인용)
2회4. 사내 견적서 양식과 부가 제출 서류
5. 기술평가·가격 협상 진행 방식
6. 수주 결과와 사후 분석		영업 임원, 견적 담당
  • 사전 요청: 최근 제출 건의 부가 서류 예시, 수주통보서·계약서 예시
3회7. 결재·권한·견적 관리 방식

(권한 범위는 영업 임원 확인)
  • 기술 검증 ①의 영업 확인 일정을 이 자리에서 함께 정함
수시기술 검증 중 확인견적 담당
  • 요약 항목 고르기, 시범 결과 확인, 규칙 후보 확인(각 30분 내외, 3번 정도)
  • 주제 1·5의 대표 승인 기준(참여 승인 기준, 반려의 의미, 협상 금액 승인 방식)은 대표께 직접 확인하면 인터뷰 시간을 줄일 수 있음.
  • 회당 1~1.5시간, 약 2~3주 안에 3회 진행을 목표로 함(영업부 일정에 맞춰 조정).

4. 기술 검증 계획

  • 개발 전에 기술적으로 불확실한 부분을 작은 시험으로 먼저 확인하는 단계임.
  • 두 검증은 서로 독립적이어서 동시에 진행할 수 있음.
구분① 지난 견적 자료 정리·검색② 도면 인식 테스트
무엇을 검증하나
  • 지난 견적 자료를 정해진 양식의 글(요약)로 정리해 두면, 별도 검색 서버 없이 AI가 필요한 사례를 잘 찾아내는지
  • AI가 배관 도면에서 용접·볼팅 포인트를 중복 없이 정확히 세고, 다이아인치(배관 용접 작업량 단위)를 얼마나 정확히 계산하는지
왜
  • AI 분석이 신입 수준을 넘으려면 지난 견적의 조건·특이사항을 참고해야 함
  • 단순한 방식으로 충분하면 서버 추가 부담 없이 시작할 수 있음
  • 지난 자료를 쓸 수 있게 정리하는 일이 곧 이 검증의 준비 작업임
  • 도면 인식이 물량 산출에서 가장 큰 기술 위험임
  • 도면 기준 물량(최소값)이 틀리면 담당자가 정하는 최종 물량도 틀어짐
어떻게
  1. 종류가 다른 지난 견적 10건을 AI가 읽고 요약 양식 초안 작성
  2. 영업이 초안 항목을 '중요 / 필요 없음 / 빠진 것'으로 선택
  3. 20~30건 시범 요약 후, 영업이 준 실제 질문 10개로 찾기 시험
  4. 정확도·응답 시간·비용을 보고 방식 결정
  5. 2024~2026 지난 견적 전체를 같은 양식으로 정리
  6. 반복되는 숨은 비용 조건(인허가, 감리, 상주 인력 등)을 AI 분석 규칙 후보로 정리, 영업 확인 후 반영
  1. 도면과 물량표(BM)가 모두 있는 지난 배관 공사 몇 건 선정
  2. 사람이 같은 도면에서 포인트·다이아인치를 직접 세어 정답표 작성
  3. AI가 도면으로 계산(최소값), 물량표로도 계산(최대값)
  4. 정답과 비교해 오차, 놓친 포인트, 중복 계산 포인트 기록
  5. 오차가 허용 범위 안이면 도면 기준을 산출에 사용, 넘으면 참고용으로만 두고 물량표 기준 사용
결과물
  • 지난 견적 요약 양식(앞으로 쌓일 데이터도 같은 양식으로 저장)
  • 검색 방식 판단 결과(현재 방식 채택 / 고급 검색 추가 검토)
  • 정리된 지난 견적 자료와 AI 분석 규칙 후보
  • 정답표·AI 결과표·비교표
  • 도면 인식 결과의 산출 반영 여부 판단
대략 기간(예상)
  • 1~4단계(시범·판단): 약 3~4주
  • 5~6단계(전체 정리·규칙 후보): 분량이 커서 별도 일정 수립
  • 영업 확인(2·3·6단계)이 일정을 좌우함
  • 약 2~3주
  • 정답표 작성(사람이 세기)에 가장 많은 시간이 듦
쓰이는 곳 참여 판단·세부 분석의 재분석, 물량·원가 재산출 때 유사 공사 참고 물량·원가 산출의 물량 검증
  • 보안: 견적 자료와 도면은 발주처 내부 자료이므로 외부에 올리지 않고 사내 환경에서만 검증함. AI에 보내는 범위는 검증 전에 정함.
  • 지난 견적 금액: 시점·경제 상황이 달라 그대로 쓰지 않으며, 조건·특이사항을 참고하는 데만 씀.
  • 미정: 검증 담당, 대상 건수, 합격 기준(정확도·허용 오차·비용 한도).

  • 기간은 예상치이며, 영업부 일정과 검증 담당이 정해진 뒤 확정함.
